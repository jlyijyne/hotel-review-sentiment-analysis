# hotel-review-sentiment-analysis
Project 15: Sentiment Analysis of Hotel Review

Follow these steps to run GUI.

Download or clone this GitHub repository and keep all files in the same folder.
Use python 3.11 or 3.12
Open terminal in that folder and run: 
    python -m pip install -r requirements.txt
    py -m streamlit run hotel_review_gui.py
the GUI should open in a web browser window.

All task codes are numbered.

Running task 12 or task 13 codes will download the Qwen LLM and take alot of memory.
